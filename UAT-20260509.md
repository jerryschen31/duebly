# User Acceptance Tests

## Universal Tests
These acceptance tests apply both to desktop and mobile browsers

1. Create a list of 10 tasks in Not Done tab, and make sure no elements - task cards, options menus (primary and secondary), dropdown menus, calendar date pickers, time dropdowns, etc - exceed (overflow) the screen boundaries and get "cut off" when displayed.
2. Add Task element: Adding a non-recurring task with a task description, start time, end time is successful.
3. Add Task element: Adding a daily recurring task with a task description, start time, end time is successful.
4. Swipe left on Not Done non-recurring task moves the task to the Done tab.
5. Swipe right on Not Done non-recurring task moves the task to the Planned tab.
6. Swipe left on Done non-recurring task deletes the task.
7. Swipe right on Done non-recurring task undos (reverts task back to either Not Done or Planned tabz).
8. Swipe left on Not Done recurring task moves the task to the next occurrence (in the Planned tab).
9. For a non-recurring task in Not Done, clicking on "Mark as Done" in the three-dot options menu moves the task to Done.
10. For a non-recurring task in Not Done, clicking on "Edit task" in the three-dot options menu brings the Task Description into focus, either as the textfield or a text area / text modal for editing the task description.

## Mobile Tests
These acceptance tests apply to mobile browsers
1. Clicking on the microphone button brings the Task Description textfield to focus and opens a mobile keyboard.
